# 行为卡：定价验证

> 触发信号：用户用“感兴趣”或口头承诺推断付费意愿
> 证据编号：WD-P5-01

## 问题本质

价格不是产品做完后的标签，而是价值假设的一部分。点击、留资、约谈、押金和真实付款的承诺成本不同，不能都叫“愿意付费”。

## 触发条件

- 用户说“先免费，后面再想怎么收费”；
- 访谈对象说愿意付钱，但没有任何有成本的行动；
- 团队引用脱离流量来源、样本和客群的通用转化率；
- 准备做预售、押金或假门测试。

## 行为指导

1. **写清付费假设**：明确谁为哪项结果付费、价格或价格区间、收费单位，以及什么证据会改变判断。
2. **选择足够强且风险最低的信号**：通常证据强度为“点击 < 留下有效联系方式 < 安排沟通 < 可退押金 < 实际付款”。只使用回答当前问题所需的最低一级。
3. **事前定义上下文门槛**：记录样本来源、客群、观察窗口和通过/待定/拒绝条件。没有跨项目通用的 `10%` 成功线。
4. **真实披露交易状态**：按钮不能真的购买时，点击后立即说明尚未开放销售；收押金或付款前写清交付范围、时间、退款和数据处理方式。
5. **分开判断价格与价值表达**：弱结果可能来自需求弱、客群错、价值表达不清或价格不合适。下一轮实验一次只改变一个主要变量。
6. **按证据作决定**：点击只能证明愿意继续了解；只有真实支付或相近成本的行为，才能支持付费意愿结论。

## 不适用场景

- 纯兴趣或完全免费的公共项目，不需要商业可行性结论；
- 未成年人、医疗、金融等高风险交易，需先满足专业和合规要求；
- 没有能力履约或退款时，不收款；
- 仅需验证可用性时，选择原型测试，不把它包装成定价验证。
