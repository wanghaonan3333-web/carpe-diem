# 行为卡：从可服务的小核心开始

> 触发信号：用户用宏大市场规模否定一个尚未服务过任何人的方向
> 证据编号：WD-P6-04

## 问题本质

早期目标不是证明项目会成为巨型公司，而是找到一小群有共同强需求、能够被亲自触达并获得明显价值的用户。小核心是学习单位，不保证未来增长。

## 触发条件

- 先讨论十亿级市场，仍说不出第一个具体用户；
- 同时追多个宽泛人群以显得市场更大；
- 等待大规模渠道，而不愿手工招募和服务；
- 把小而可持续的项目自动判为失败。

## 行为指导

1. **写出最小用户群**：共同情境、迫切任务、现有替代和可触达地点必须具体。
2. **亲自招募首批用户**：用直接沟通验证他们是否愿意投入时间、数据、迁移或付费。
3. **提供高接触服务**：手工完成暂时无法自动化的部分，记录哪些需求重复、哪些只是个例。
4. **验证局部密度**：观察该小群体内使用、留存、推荐或重复请求是否自然形成，不用总注册量掩盖空洞。
5. **决定项目目标**：明确追求公益、可持续小生意、工具影响力还是高增长；不同目标使用不同门槛。
6. **用相邻证据扩张**：只有核心价值稳定且新群体共享关键需求时才扩大，不从故事直接推导大市场。

## 不适用场景

- 强网络效应、基础设施或监管业务可能需要最小可运行网络和更大初始投入；
- 小群体中的偏见不能外推到所有用户；
- 高接触服务应尊重隐私、劳动和承诺边界；
- 本卡不主张所有项目都必须商业化或扩张。
