# 行为卡：故事式用户访谈

> 触发信号：访谈得到大量观点和功能愿望，却没有具体行为上下文
> 证据编号：WD-P5-05

## 问题本质

人们对未来行为的预测和对一般习惯的概括并不可靠。访谈应收集最近一次真实经历的故事，同时承认定性样本不能预测总体比例。

## 触发条件

- 主要问题是“你会不会用”“你觉得怎么样”；
- 访谈大部分时间用于介绍方案；
- 只记录结论，没有用户原话和事件顺序；
- 用少数访谈直接推算市场规模或转化率。

## 行为指导

1. **先写研究问题**：明确要理解的决策，不把研究问题原样问给用户。
2. **邀请最近故事**：从“告诉我最近一次……”开始，追问触发、过程、替代方案、阻碍、结果和情绪。
3. **沿时间线追问**：用“然后发生了什么”“你当时做了什么”获取行为，不用连续“为什么”逼迫用户合理化。
4. **控制推销冲动**：用户故事阶段不演示、不纠正；需要测试方案时另开明确的原型环节。
5. **分开事实与解释**：记录原话和动作，再单列团队解释、反例及未知项。
6. **只作适当结论**：访谈用于发现模式和生成假设；频率、因果和付费结论需要其他实验支持。

## 不适用场景

- 需要统计总体比例时，使用合适的量化研究；
- 敏感、创伤或受保护人群研究需专业伦理流程；
- 用户没有相关经历时，不强迫其编造故事；
- 本卡不替代可用性测试、定价实验或产品分析。
