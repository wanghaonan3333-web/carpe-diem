# 项目类型模板

> 不同项目类型有不同的开发模式、验证策略和常见陷阱。
> 这些模板帮助用户在 Discover 和 Validate 阶段快速理解自己的项目适合什么开发模式。

## 使用方式

当用户进入 Plan 阶段并确认了项目方向后，加载与用户方向匹配的项目类型模板：

1. 根据用户描述的项目类型选择模板
2. 阅读模板中的"对 Carpe Diem 各阶段的启发"部分，获取针对 Discover/Validate/Plan 的指导
3. 将模板中的"Prompt 模式"用于指导用户与 Coding Agent 协同工作
4. 参考"验证策略"设计项目的测试方案
5. 使用"常见陷阱"和"反向提醒"帮助用户避免常见错误

## 可用模板

| 模板 | 适合的场景 | 典型用户 |
|------|-----------|----------|
| `cli-tool.md` | CLI 工具、脚手架、代码生成器、格式化工具 | 开发者、运维、数据分析师 |
| `web-app.md` | Web 应用、API 服务、仪表盘、SaaS 产品 | 普通用户、企业用户 |
| `devtool.md` | IDE 插件、CI/CD 工具、代码分析工具、调试工具 | 开发者 |

## 模板结构

每个模板包含以下章节：

- **问题本质** — 这类项目解决了什么核心问题
- **典型特征** — 目录结构、技术栈选择、依赖关系模式
- **对 Carpe Diem 各阶段的启发** — Discover/Validate/Plan 阶段的注意事项
- **Prompt 模式** — 给 Coding Agent 写 Prompt 时的最佳实践
- **验证策略** — 如何验证输出质量和测试策略
- **常见陷阱** — 最容易踩的坑
- **反向提醒** — 不适合做什么

## 与 references/wisdom/real-world-patterns/ 的区别

`real-world-patterns/` 包含从 AI 公司博客和工程实践中提取的**通用实战模式**（如"如何构建有效的 Agent"、"如何管理上下文工程"），适用于所有项目类型。

`project-archetypes/` 包含针对**特定项目类型**的开发模板（如"CLI 工具怎么做"、"Web 应用怎么规划"），适用于特定方向的项目。

两者互补：实战模式卡片提供通用方法论，项目类型模板提供针对性指导。
